## Title

```
Independent zero count as a completeness route for zero_layer.py
```

## Body

```
`hunts/skewes_enclosure/zero_layer.py` documents a gap in its own docstring:

    Route 2 shares no code with Arb: mpmath's ``siegelz`` ... It does not check
    completeness: the count is the layer both routes share, through Arb's Turing
    count, unless an independent count is added.

I have been using an independent count for exactly that purpose and it does catch things
the shared count cannot. Reporting it here because the docstring invites it; happy to send
a patch in whatever shape fits, or to leave this as an observation for whoever owns the
layer.

## What I used

`mpmath.nzeros(T)` (Turing's method) at points strictly between ordinates, differenced:

    inside = nzeros(hi) - nzeros(lo)        # lo, hi strictly between ordinates

Two implementation notes that cost me time and are worth recording:

1. **Do not call nzeros at an ordinate.** Floating-point rounding makes
   `nzeros(gamma_k)` return k or k-1 unpredictably. Measured: nzeros(gamma_3) = 2, not 3.
   Evaluate at midpoints between consecutive ordinates instead.
2. At T ~ 7e4 this takes ~0.09 s, versus ~1.5e4 zeta evaluations for the same window
   by the argument principle. The argument-principle route is the certified one; nzeros
   is the cheap independent cross-check.

## The negative control, which is the point

Odlyzko's `zeros1` (100,000 ordinates, height <= 74920.8, sha256
3436c916a7878261ac183fd7b9448c9a4736b8bbccf1356874a6ce1788541632).

Table intact  -> windows 200/200, 200/200, 200/200
Same file, one row deleted at index 50,050 -> 200/200, 201 vs 200, 200/200

The weak count-versus-smooth check does NOT catch it: implied |S(T)| = 0.405, which passes
any "|S(T)| < a few" test. Only the independent windowed count fails, and it fails at the
right window.

Artifacts (JSON, generated by the pipeline, no hand-typed figures):
  https://github.com/KIDA-Nya/zeta-audit/blob/main/out/odlyzko_audit.json
  https://github.com/KIDA-Nya/zeta-audit/blob/main/out/odlyzko_negative_control.json

## Honest scope

- This is float grade, not Arb. It is a second opinion, not a certificate; it cannot
  replace route 1 and I am not claiming it does.
- It is sampled: a hole outside the sampled windows is missed. A full sweep costs a
  `nzeros` call per window, which for the 2e6-zero range is ~10^4 calls at ~0.1 s.
- For a certified independent count the argument-principle version in `certify.py` is the
  right tool; it is just too slow above T ~ 1e3 in pure Python.
```

## Why this framing

- **It leads with their own words.** The gap is quoted from their docstring, so the issue is
  answering an invitation rather than proposing an agenda.
- **The negative control is the evidence.** Anyone can claim a better check; the deleted-row
  result is what makes it checkable in one minute.
- **Scope is stated before anyone asks.** Float not Arb, sampled not exhaustive, and an
  explicit "cannot replace route 1". Their `ALIGNMENT.md` §2 is precisely about not
  overstating what was checked, so matching that register matters more than enthusiasm.
- **No ask beyond the observation.** "Happy to send a patch in whatever shape fits, or leave
  it as an observation" gives the maintainer an exit that is not a rejection.
